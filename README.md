# Sistema de Apoio às Ações de Vacinação no PSE

Projeto desenvolvido para a Atividade de Estudo Programado (AEP) do curso de Engenharia de Software.

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema em linguagem C para auxiliar no registro, na organização e no acompanhamento de ações coletivas de vacinação relacionadas ao Programa Saúde na Escola (PSE).

A proposta busca aplicar conhecimentos de Algoritmos e Lógica e Engenharia de Software, utilizando uma solução simples para organizar informações sobre as ações realizadas.

## Objetivo

Desenvolver um sistema capaz de registrar e acompanhar ações de vacinação, permitindo consultar informações e gerar um resumo dos resultados obtidos.

## Funcionalidades

* Cadastro de ações de vacinação;
* Listagem das ações cadastradas;
* Pesquisa de ações;
* Atualização da situação das ações;
* Registro da quantidade de participantes efetivos;
* Geração de resumo estatístico.

## Privacidade

O sistema utilizará dados fictícios e informações coletivas para fins acadêmicos.

A proposta não contempla:

* Diagnósticos;
* Prontuários;
* Condições clínicas individuais;
* Dados pessoais sensíveis dos estudantes.
